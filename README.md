## Getting Started

### Prerequisites

- Python 3 installed on your system
- Git installed on your system
- A code editor such as Visual Studio Code or PyCharm

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/samruddhimandage/PYTHON_Practice.git
```

**2. Navigate to the project directory**

```bash
cd PYTHON_Practice
```

**3. (Optional) Create a virtual environment**

```bash
python -m venv venv
```

Activate the environment:

- Windows:

```bash
venv\Scripts\activate
```

- macOS/Linux:

```bash
source venv/bin/activate
```

**4. Run a Python program**

Navigate to the relevant project folder and execute the desired Python script:

```bash
python filename.py
```

Replace `filename.py` with the actual name of the script you want to run.

**5. Install dependencies if required**

If a project contains a `requirements.txt` file, install its dependencies using:

```bash
pip install -r requirements.txt
```
